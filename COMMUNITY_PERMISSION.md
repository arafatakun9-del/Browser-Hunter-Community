# Community Permission & Project Direction

The project owner explicitly welcomes independent Android developers and contributors to use the public Browser Hunter source code to build, improve, or rebuild the app.

## Permission

The source code is released under the MIT License. You may study, modify, build, and distribute your own versions in accordance with that license.

## Please preserve the project identity

When creating a community build or derivative app from this project, the owner's clear request is to keep the product name **Browser Hunter** rather than changing it to an unrelated app name. Please retain appropriate project attribution and link back to this community repository when practical.

## Product requirements to respect

- Android-native app using the installed Chromium WebView engine only.
- No Firefox or extra browser engine.
- Lightweight performance suitable for phones with around 4 GB RAM.
- Fast everyday browsing, desktop-site mode, and a useful download manager.
- Reliable direct downloads with clear status, queue, pause/resume/cancel, and recovery where supported.
- Social-media extraction is site-dependent and must not be advertised as universal.
- Privacy and security must be reviewed and tested; do not ship exposed API keys or private credentials.
- Keep the interface clean, practical, and friendly to Bengali and English users.

You are welcome to propose a better architecture or replace weak implementations if the result follows these goals. Please submit focused pull requests or explain your changes so the owner and other contributors can review them.

## Important

The public repository is a sanitized source snapshot. It intentionally does not include the owner's personal portrait images, private AI Studio uploads, API secrets, signing keystores, or private repository history. The APK is not yet a verified public release.
